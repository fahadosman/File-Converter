Files Converter

Welcome to our user guide

We designed Files Converter to be simple, but this guide explains each workflow clearly so you can move faster.

Organize PDF

Merge PDF

Upload two or more PDF files from your device, Google Drive, or Dropbox, then reorder them before combining. Password-protected files are supported once unlocked for processing. When ready, click merge and download one PDF.

Split PDF

Upload a PDF and split by custom page ranges, extract every page, or combine selected ranges into one output. You can process protected files after entering credentials.

Remove Pages

After upload, each page appears as a thumbnail. Select pages to remove, then run processing and download the cleaned file. Multi-file uploads are color-framed for easier page identification.

Extract Pages

Pick pages you want to keep, then choose either one merged PDF output or a ZIP package with separate extracted pages.

Organize PDF

Rearrange page order with drag-and-drop and remove unwanted pages before exporting the reorganized document.

Optimize and Edit PDF

Compress PDF

Choose regular, high, or extreme compression. Stronger compression usually gives smaller files with more quality reduction. Download the result or save back to cloud storage.

Edit PDF

Use the editor toolbar to add text, images, and shapes, adjust style properties, move/resize items, zoom, and navigate pages. Finalize by clicking Edit PDF to process and export.

Add Page Numbers

Number all pages or selected ranges/facing pages, then customize position, style, size, color, and opacity before export.

Add Watermark

Apply text and/or image watermark to every page with custom rotation, position, transparency, and formatting settings.

Repair PDF

Upload damaged PDF files and Files Converter will attempt to analyze and recover readable content automatically.

Convert to PDF

JPG to PDF

Convert one or many images to PDF, set page orientation and margin, and optionally merge all images into a single document.

Word to PDF

Upload DOCX files and convert into non-editable PDF output while preserving content layout.

PowerPoint to PDF

Convert PPTX presentations into PDF documents with slides, text, and visuals transferred into fixed pages.

Excel to PDF

Convert XLS/XLSX sheets into non-editable PDF documents with table and chart content preserved.

HTML to PDF

Paste a page URL, review preview output, adjust orientation/margins, then export the webpage as a PDF file.

Convert from PDF

PDF to JPG

Convert full pages into JPG images or extract embedded images into a ZIP package.

PDF to Word

Transform PDFs into editable DOCX files and download instantly or save directly to cloud drives.

PDF to PowerPoint

Convert PDF pages to editable PPTX slides, typically one PDF page per slide.

PDF to Excel

Convert tables and structured data from PDF files into editable XLSX spreadsheets.

PDF Security and Signature

Unlock PDF

Remove password protection from PDFs you are authorized to edit.

Protect PDF

Add a user-defined password to encrypt and secure your PDF document.

PDF to PDF/A

Convert PDFs to PDF/A format for long-term archiving and compliance workflows.

Sign PDF

Add your own signature by drawing, uploading, or typing; include date/initial fields. You can also create signature requests and collect e-signatures with an auditable trail.

Technical concepts

Password-protected files

We ask for the password only to open/process your file and do not store it on our servers.

Rotating and organizing files

Rotate per file/page, batch rotate when available, drag-drop reorder, and sort alphabetically or reverse alphabetically.

Compression expectations

You will see original size and reduction percentage. Already optimized PDFs may not shrink further.

Uploading, processing, and download retention

Processing time depends on network speed, file size, and server load. Download availability depends on user plan. You can save outputs back to Google Drive/Dropbox and revoke shared download access when needed.

Working from the cloud

Files Converter supports direct cloud import/export so files do not need to be stored locally first. This is especially useful on mobile and tablet devices.

Selecting multiple files

Use Ctrl-click for non-consecutive selections, Shift-click for ranges, or simply drag and drop into the canvas.

Minimum requirements and troubleshooting

Recommended browsers are Chrome, Firefox, Explorer 10+, and Safari with JavaScript enabled. If you run into issues, contact support and attach a sample file when possible (non-confidential) to speed diagnosis.
